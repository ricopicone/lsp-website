# Cartel Formation Workflow Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Re-sequence the cartel workflow so a cartel forms *among members first* (visible + joinable from proposal), then gets submitted to the Programming Committee for registration as the final step — adding a per-member "question" and a submit gate.

**Architecture:** A cartel is a `Workgroup(kind=cartel)` + thin `Cartel`. We add an orthogonal `Cartel.registration_status` (FORMING → SUBMITTED → REGISTERED) that tracks *only* the PC cycle. The workgroup's `WorkgroupProposal.status` is set to `OPEN` from propose onward, so the cartel is live/joinable immediately and every existing gate (`governance_state`, `apply`, `accept_invitation`, roster) keeps working unchanged; archived cartels keep `proposal.status=ARCHIVED`. Per-member questions live in a dedicated `CartelQuestion` model to keep the shared Workgroup layer clean.

**Tech Stack:** Django 5.2 / Python 3.10+, uv, pytest-django, ruff, Tailwind v4 + DaisyUI (templates only — no Python-set classes), SQLite (dev) / Postgres (prod).

## Global Constraints

- **State axis:** `WorkgroupProposal.status` = `OPEN` for a live cartel throughout FORMING/SUBMITTED/REGISTERED; `ARCHIVED` when archived. `Cartel.registration_status` is the source of truth for the formation flow. Never add cartel-specific values to the shared `WorkgroupProposal.Status`.
- **Submit gate (required):** plus-one assigned (internal role *or* an `ExternalPlusOne`); `start_date` + `end_date` set with `365 ≤ (end − start).days ≤ 731`; **3–5 cartelisands** counting active members **excluding** the plus-one. Per-member questions are **recommended, never blocking**.
- **Duration bound** is enforced **only at submit** (a forming cartel may hold a rough/out-of-range window earlier).
- **Coordinator** is notified when a cartel starts forming and advises anytime (non-binding). **PC** is notified at **submit**, not at propose. Invitees are notified **at propose**.
- **Per-member question:** each cartelisand edits **only their own**; **all cartelisands read all**; included in the PC submission view.
- **Site copy** uses commas, not em dashes (member-facing style rule). Use DaisyUI semantic tokens only.
- **do-not-over-automate:** keep human escape hatches; questions never block; the checklist is advisory-forward.
- Run `uv run pytest cartels/ -q` and `uv run ruff check cartels/` green before finishing.

    def propose(self, *, generator, name, guiding_question="", description="", invitees=()):
        """A member starts a cartel forming (task #392 step 1).

        The cartel is live among the school immediately (members-visible landing,

            description=description,

            content_visibility="private",

            workgroup=wg, guiding_question=guiding_question,
            registration_status=self.model.RegistrationStatus.FORMING,

        cartel.add_member(generator)
        for user in invitees:
            WorkgroupInvitation.objects.get_or_create(
                workgroup=wg, invited_user=user, defaults={"created_by": generator},
            )
        return cartel

```python
    # ---- Registration (submit-to-PC) gate ----

    #: Cartel size bounds (cartelisands; the plus-one is extra).
    MIN_CARTELISANDS = 3
    MAX_CARTELISANDS = 5

    def cartelisand_count(self) -> int:
        """Active members excluding whoever holds the plus-one role."""
        return self.workgroup.memberships.serving().exclude(
            role=WorkgroupMembership.Role.PLUS_ONE
        ).count()

    def has_plus_one(self) -> bool:
        internal = self.workgroup.memberships.serving().filter(
            role=WorkgroupMembership.Role.PLUS_ONE
        ).exists()
        return internal or self.external_plus_ones.exists()

    def duration_ok(self) -> bool:
        start, end = self.workgroup.start_date, self.workgroup.end_date
        if not (start and end):
            return False
        days = (end - start).days
        return 365 <= days <= 731

    def registration_checklist(self) -> dict:
        count = self.cartelisand_count()
        plus_one = self.has_plus_one()
        duration = self.duration_ok()
        in_range = self.MIN_CARTELISANDS <= count <= self.MAX_CARTELISANDS
        total = count
        done = self.member_questions.exclude(text="").count()
        return {
            "plus_one": plus_one,
            "duration": duration,
            "count": in_range,
            "count_value": count,
            "questions_done": done,
            "questions_total": total,
            "can_submit": bool(plus_one and duration and in_range),
        }

    @transaction.atomic
    def submit_for_registration(self, by):
        """Any cartelisand submits the cartel to the PC for registration once
        the required gate passes (questions stay optional)."""
        if not self.registration_checklist()["can_submit"]:
            raise ValidationError("The cartel is not ready to submit for registration.")
        self.registration_status = self.RegistrationStatus.SUBMITTED
        self.save(update_fields=["registration_status"])
        proposal = self.workgroup.proposal
        if proposal.review_note or proposal.reviewed_by_id:
            proposal.review_note = ""
            proposal.reviewed_by = None
            proposal.reviewed_at = None
            proposal.save(update_fields=["review_note", "reviewed_by", "reviewed_at"])
```
