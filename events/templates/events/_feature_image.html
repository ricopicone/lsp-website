{% comment %} An event's feature image (task #504). Both dimensions are bounded rather than the height being fixed: the image is never taller than the band and never wider than the column, and is never asked to be both at once. So a 2.5:1 runs the column's full width, a square sits as a narrow plate, and on a phone, where the width bound binds first, everything simply gets shorter. Nothing is cropped at display time; the shape was settled at upload. The phone bound is the looser of the two on purpose: at that width anything wide is already bound by the column, so the height cap only ever governs the squarer end, where 200px left a poster stranded beside empty space.
